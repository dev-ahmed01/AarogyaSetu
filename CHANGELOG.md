# Changelog

## 1.0.0 — 2026-10-07

Aarogya v1.0.0 completes the 16-phase academic research prototype roadmap.

Highlights:

- Next.js responsive health/nutrition product experience
- Java 21 Spring Boot modular-monolith API
- PostgreSQL + Flyway system of record
- authentication, refresh rotation and RBAC
- consent-aware health profile
- source/provenance-aware food catalog
- meal logging with immutable snapshots
- deterministic explainable recommendation engine
- diet-plan drafts and smart food suggestions
- mock-only ABDM/ABHA integration architecture
- explainable nudges and alert lifecycle
- regional dietary intelligence
- gentle goals, streaks and achievements
- longitudinal descriptive analytics
- nutritionist/admin content operations
- privacy-thresholded research evaluation
- personal-data export and account deletion
- production configuration guard
- authentication rate limiting
- non-root Docker images
- full-stack Docker Compose
- PostgreSQL-backed CI and container build gate

The release remains an academic wellness/research prototype and does not provide diagnosis, treatment, live ABDM connectivity or official Government of India functionality.
